# Portfolio Website

Personal portfolio built with HTML, CSS and JavaScript — no frameworks, no build step.

## About

A creative portfolio to showcase my projects and skills as a Software Development student, with a design inspired by music players and editorial layouts.

## Live Demo

[GitHub Pages](https://arthrtx.github.io/portfolio-website/)

## Projects

- **PinSpace Create** — web app for mood boards and collages, Canva + Pinterest style ([live](https://glittery-gaufre-d6756f.netlify.app/) · [code](https://github.com/arthrtx/PinSpace_Create))
- **FitControl** — gym management desktop app in Python with facial recognition ([code](https://github.com/arthrtx/FitControl))
- **Game Collection** — Android app in Kotlin + Jetpack Compose to organize a video game collection ([code](https://github.com/arthrtx/GameCollection))

## Features

- Hero with a scrolling wall of screens and a smooth transition into the projects
- Projects shown as a coverflow in a music-player layout, with video previews
- Project pages with screenshots, gallery and links, opened inside the site
- Built-in music player with original house tracks generated live (Web Audio API) — no copyright
- Mini player that keeps the music going while you browse
- "About me" paper sheet you can pull open
- Slide-out contact panel
- English / Portuguese language toggle
- Responsive design (desktop, tablet and mobile)

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Web Audio API
- Font Awesome
- Google Fonts
